# MD-MWCNT-PEEK-CF-Heterogeneous-Composites  This dataset contains the comprehensive raw data, configuration files, and analysis scripts from a Molecular Dynamics (MD) simulation study titled "Integrated Molecular Dynamics Analysis of Load Bearing, Thermal Transport, Kapitza Resistance and Damage Evolution in MWCNT/PEEK/CF/GH4169 Heterogeneous Composites". The files are structured systematically to ensure reproducibility and allow researchers to explore the mechanical, thermal, and interfacial properties of this complex heterogeneous composite system.
